# SAIMS Frontend Documentation (`docs/frontend/`)

Selamat datang di modul dokumentasi teknis Frontend SAIMS berbasis **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, dan **TypeScript**.

## Quick Start Frontend App

```bash
# 1. Install Dependencies
cd frontend
npm install

# 2. Jalankan Dev Server (Port 3000)
npm run dev
```
